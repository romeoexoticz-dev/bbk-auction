# BBK AUCTION

ระบบประมูลของสะสมที่สร้างใหม่ด้วย Next.js, Vercel และ Supabase โดยแยกพอร์ทัลลูกค้า ผู้ขาย และแอดมิน แต่ใช้ฐานข้อมูลกลางเดียวกัน

โหมดเปิดตัวใช้ BBK เป็นผู้ขายเพียงรายเดียว สมาชิกทั่วไปสมัครเพื่อเข้าร่วมประมูล และยังไม่เปิดรับผู้ขายภายนอก

## เริ่มใช้งานในเครื่อง

```powershell
pnpm install
Copy-Item .env.example .env.local
pnpm dev
```

จากนั้นเปิด `http://localhost:3000`

## เชื่อม Supabase

1. นำค่า Project URL และ Publishable key จาก Supabase ใส่ `.env.local`
2. เปิด SQL Editor ใน Supabase แล้วรัน migration ตามลำดับใน `supabase/migrations`
3. ตั้งค่า Site URL และ Redirect URL ของ Auth ให้ตรงกับ localhost/Vercel
4. อย่านำ Secret key ไปใส่ตัวแปร `NEXT_PUBLIC_*`

## อนุมัติผู้ประมูลแบบฟรี

รัน migration `202609230013_email_admin_bidder_approval.sql` หลัง migration ก่อนหน้า สมาชิกต้องยืนยันอีเมลกับ Supabase แล้วเปิดหน้า `/account/verification` เพื่อส่งคำขอให้แอดมินตรวจ เมื่อแอดมินอนุมัติจึงวางประมูลได้ วิธีนี้ไม่ส่ง SMS และไม่มีค่าบริการ Twilio

## ค่าธรรมเนียมและคำสั่งซื้อ

รัน migration `202609230014_fee_orders_notifications.sql` เพื่อเปิดกติกาค่าธรรมเนียมผู้ซื้อ 10% + VAT 7% ของค่าธรรมเนียม, ขั้นเพิ่มราคา 10/50/100 บาท, การสร้าง Order เมื่อปิดประมูล และการแจ้งเตือนภายในเว็บ ผู้ใช้ดูประวัติได้ที่ `/account` และดูยอดแยกใน `/orders/[id]`

รัน migration `202609240026_bid_rate_limits.sql` หลัง migration ก่อนหน้าทั้งหมด เพื่อบังคับเว้นอย่างน้อย 2 วินาทีต่อการเสนอราคา จำกัด 10 ครั้งใน 60 วินาทีต่อบัญชี และเปิดบันทึกคำขอที่ถูกปฏิเสธในหน้า `/admin#bid-security`

ระบบรับเงินจริงและแนบสลิปยังปิดไว้จนกว่าจะตั้งค่าบัญชี/QR ร้านและค่าจัดส่ง

ขั้นตอนแบบละเอียดอยู่ที่ `docs/CONNECT-SUPABASE.md`

## เส้นทางหลัก

- `/` ตลาดประมูลสำหรับลูกค้า
- `/account` ประวัติ bid รายการที่ชนะ และการแจ้งเตือน
- `/seller` ศูนย์จัดการผู้ขาย
- `/admin` ศูนย์ควบคุมแอดมิน

อ่านกติกาและสิ่งที่ยังต้องตัดสินใจก่อนเปิดจริงได้ที่ `docs/AUCTION-DESIGN.md`

> ขณะนี้เป็น Foundation prototype และระบบเงินจริงถูกปิดไว้
