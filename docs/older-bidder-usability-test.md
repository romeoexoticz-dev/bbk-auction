# ทดสอบการใช้งานมือถือกับผู้ประมูลอายุ 55 ปีขึ้นไป

สถานะ: แบบทดสอบพร้อมใช้ — ยังไม่ได้ทดสอบกับคนจริง

## เตรียมก่อนเริ่ม

- ใช้ผู้ทดลอง 5 คน อายุ 55 ปีขึ้นไป คนละเครื่องหรือคนละเซสชัน ไม่ใช้บัญชีของคนอื่นร่วมกัน
- ใช้เฉพาะรายการที่ติดป้าย `TEST — ไม่ขายจริง` และบัญชีที่ได้รับสิทธิ์เสนอราคาแล้ว ห้ามใช้รายการขายจริง
- ตรวจว่ารายการ TEST ยังเปิดอยู่ มีเวลาเหลือพอ และระบบชำระเงินจริงปิดอยู่
- ไม่บอกตำแหน่งปุ่มหรือขั้นตอนบนหน้าจอ และไม่ช่วยระหว่างการทำงาน ยกเว้นหยุดเพื่อความปลอดภัย
- ไม่บันทึกรหัสผ่าน เลขโทรศัพท์ หรือข้อมูลส่วนตัวในใบบันทึกนี้

## คำสั่งที่อ่านให้ผู้ทดลองฟัง

“ลองใช้มือถือหา ‘รายการ TEST — ไม่ขายจริง’ ที่กำลังประมูลอยู่ แล้วเสนอราคาขั้นต่ำหนึ่งครั้ง จากนั้นบอกว่าเห็นหรือไม่ว่าระบบรับราคาแล้ว ทำด้วยตัวเองได้เลย หากไม่แน่ใจให้พูดสิ่งที่กำลังคิดออกมาได้”

เริ่มจับเวลาเมื่อผู้ทดลองเปิดหน้าแรก หยุดเมื่อเห็นข้อความยืนยันว่าเสนอราคาสำเร็จ หรือเมื่อครบ 5 นาที ห้ามชี้นำระหว่างทาง
