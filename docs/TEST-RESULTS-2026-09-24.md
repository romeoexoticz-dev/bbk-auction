## ข้อค้นพบที่ต้องแก้ก่อนเปิดจริง

- ฐานข้อมูลปัจจุบันยังไม่มีคอลัมน์ความน่าเชื่อถือสินค้าจาก migration `024` เช่น `item_year` แม้ไฟล์ migration มีอยู่ในโปรเจกต์ จึงต้องติดตั้งและตรวจ schema ก่อนทดสอบส่วนข้อมูลสินค้า
- การปฏิเสธ bid หลังเส้นตายที่เห็นเป็น `AUCTION_NOT_LIVE` เพราะงานปิดอัตโนมัติเปลี่ยนสถานะเป็น `ended` ก่อนคำขอเข้าถึงฟังก์ชัน ไม่ใช่ข้อผิดพลาดของการตรวจขั้นต่ำราคา

## ยังไม่ได้ทดสอบ

- bid ที่เข้าตรงเส้นตายแบบโหลดจำนวนมาก (ชุดนี้ยืนยันเฉพาะหลังเส้นตายและ 2 การเชื่อมต่อ)
- การหลุดและเชื่อม Realtime ใหม่ระหว่างมี bid
- การกู้คืนฐานข้อมูลจาก backup

ผลชุดนี้ยืนยัน idempotency, การแย่งเสนอราคาจากสองการเชื่อมต่อ, การปิดอัตโนมัติ และการปิดพร้อมกันได้ แต่ยังไม่ใช่หลักฐานว่าระบบพร้อมเปิด production จนกว่าการทดสอบโหลด, Realtime reconnect, migration ที่ค้าง และการกู้คืนจะผ่าน
