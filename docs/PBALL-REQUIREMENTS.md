# งานจากพี่บอล — สถานะพัฒนา BBK Auction

อัปเดต: 25 กันยายน 2026

## กติกาที่คุณตาลอนุมัติแล้ว

- ร้าน BBK เป็นผู้ขายรายเดียวในช่วงเริ่มต้น
- ค่าธรรมเนียมผู้ซื้อ 10% และ VAT ของค่าธรรมเนียม 7% รวมเป็น 10.7%
- เพิ่มราคาขั้นต่ำ: ต่ำกว่า 1,000 บาทเพิ่ม 10 บาท, 1,000–4,999 บาทเพิ่ม 50 บาท, ตั้งแต่ 5,000 บาทเพิ่ม 100 บาท
- ผู้ชนะชำระด้วย QR/โอนและแนบสลิปภายใน 24 ชั่วโมง
- ไม่ชำระครั้งแรก: ยกเลิกและเตือน; ครั้งที่สอง: ระงับและรอแอดมินตรวจ
- ผู้ประมูลยืนยันอีเมลและผ่านการอนุมัติจากแอดมิน
- จำกัดการเสนอราคาต่อบัญชี: เว้นอย่างน้อย 2 วินาที และไม่เกิน 10 ครั้งใน 60 วินาที
- ต่อเวลาอัตโนมัติ: หากมี bid ที่ยอมรับใน 2 นาทีสุดท้าย ให้ต่ออีก 2 นาที และทำซ้ำจนไม่มี bid ช่วงท้าย
- ตัวนับเวลาลูกค้าเทียบเวลาฐานข้อมูลทุก 30 วินาทีและเมื่อกลับเข้าแอป โดยไม่เชื่อนาฬิกามือถือเป็นหลัก
- หน้ารายการแสดงประวัติราคาแบบชื่อแทนเฉพาะรายการ โดยไม่เปิดเผยข้อมูลบัญชีผู้ประมูล
- บัญชีลูกค้าแยกรายการที่กำลังประมูล ชนะ และไม่ชนะ โดยนับหนึ่งรายการต่อหนึ่งการประมูล
- ระบบรับเงินจริงยังปิดจนกว่าจะยืนยันบัญชีร้าน

## P1 — ความน่าเชื่อถือของสินค้า

| งาน | สถานะ | สิ่งที่ต้องทำ |
|---|---|---|
| ภาพหน้า หลัง และตำหนิ | พร้อมติดตั้งฐานข้อมูล | แบบฟอร์มบังคับ 3 ประเภท แสดงภาพจริงด้วย signed URL และกันเปิดรายการหากรูปไม่ครบ |
| ประเภท ปี รุ่น ขนาด สภาพ รายละเอียด | พร้อมติดตั้งฐานข้อมูล | แยกฟิลด์ครบและกันเปิดรายการหากข้อมูลไม่ครบ |
| เงื่อนไขรับประกัน/คืนสินค้า | รอข้อมูลเจ้าของ | ต้องใช้ข้อความที่พี่บอลอนุมัติ |
| คำเตือนการประเมินจากภาพ | ยกเลิกตามนโยบายร้าน | คุณตาลยืนยันว่าร้านคัดลงเฉพาะของแท้ จึงไม่แสดงคำเตือนนี้ |
| หมายเหตุผู้เชี่ยวชาญ | พร้อมติดตั้งฐานข้อมูล | มีช่องหลังบ้านและแสดงแยกจากคำอธิบายทั่วไป |
| ลายน้ำภาพสินค้า | ต้องทำ | สร้างลายน้ำลงไฟล์ภาพที่เผยแพร่ ไม่ใช่เพียง CSS ทับหน้าเว็บ |
| ช่องทางติดต่อทางการ | รอข้อมูลเจ้าของ | ต้องใช้บัญชีและเบอร์ธุรกิจที่ยืนยันแล้วเท่านั้น |

## P1 — การแจ้งเตือน

| งาน | สถานะ |
|---|---|
| ถูกเสนอราคาสูงกว่า | ทำแล้ว |
| ก่อนหมดเวลาประมูล | ติดตั้งและทดสอบแล้ว: แจ้งผู้ที่เคยเสนอราคาเมื่อเหลือไม่เกิน 15 นาที ส่งครั้งเดียวต่อบัญชีต่อรายการ |
| แจ้งผู้ชนะและผู้ไม่ได้สินค้า | ทำแล้ว |
| ใกล้ครบกำหนดชำระ | ทำแล้ว |
| แจ้งเตือนภายในเว็บไซต์ | ทำแล้ว |
| โครงสร้างช่องทางภายนอก | มี Web Push แบบปิดไว้; LINE/อีเมล/SMS ยังไม่เปิด |

## P2 — รองรับการขยายระบบ

| งาน | สถานะ |
|---|---|
| หลายรายการพร้อมกัน | ทำแล้วในระดับโครงสร้าง |
| หมวดหมู่สินค้า | ทำแล้ว |
| 200–300 รายการต่อวัน | เพิ่ม pagination ฝั่งฐานข้อมูลแล้ว ยังต้องทดสอบโหลด |
| ค้นหาและกรอง | ทำแล้ว: ค้นชื่อ/รายละเอียด กรองหมวด และเก็บตัวกรองใน URL |
| ปฏิทินประมูล | ต้องทำ |
| ผู้ขายภายนอก | โครงสร้างมีแล้วและถูกปิดด้วย single-seller mode |
| แยกสิทธิ์ละเอียด | บางส่วน: bidder/seller/admin/support/finance; ยังไม่มี reviewer/super-admin ตามชื่อใหม่ |
| รายงานธุรกิจ | ทำแล้ว: เลือกช่วงวันที่ สรุปยอดประมูล ค่าธรรมเนียม ยอดชำระ ยอดรอชำระ และสินค้าค้างส่ง |
| ส่งออก CSV/Excel | ทำแล้ว: จำกัดสิทธิ์แอดมิน รองรับ CSV UTF-8 และ Excel ที่มีหน้าสรุป/รายละเอียด/สินค้าค้างส่ง |

## P2 — ความปลอดภัยและความเสี่ยง

| งาน | สถานะ |
|---|---|
| ป้องกันคำสั่งเสนอราคาซ้ำ | ทำแล้วด้วย idempotency key |
| จำกัดความถี่เสนอราคา/ป้องกันบอต | ติดตั้งและทดสอบแล้ว: ล็อกต่อบัญชี 2 วินาที/10 ครั้งต่อนาที บันทึกคำขอที่ถูกปฏิเสธให้แอดมินตรวจ และปิดการเรียกใช้สำหรับผู้ไม่เข้าสู่ระบบ |
| Audit Log | ทำแล้วสำหรับราคา สถานะ การชำระ และงานแอดมินหลัก |
| สำรองและกู้คืนข้อมูล | ยังไม่ได้ยืนยันด้วยการทดสอบกู้คืน |
| ซ่อนข้อมูลส่วนตัว | มี RLS และหน้าลูกค้าไม่แสดงข้อมูลผู้ใช้รายอื่น |
| รายงานบัญชี/รายการผิดปกติ | ต้องทำ |
| หน้าเตือนช่องปลอม | ต้องทำ |
| Privacy Policy / Terms | ต้องให้เจ้าของและผู้เกี่ยวข้องอนุมัติข้อความก่อนเปิดจริง |

## ลำดับพัฒนาที่แนะนำ

1. Product trust: ฟิลด์ข้อมูลสินค้า + ภาพจริงแบบมีบทบาท + ลายน้ำ + คำเตือน
2. Auction ending reminder: แจ้งเตือนในเว็บแบบไม่ส่งซ้ำ
3. Search/filter/pagination รองรับจำนวนรายการมากขึ้น
4. ช่องรายงานบัญชีหรือรายการผิดปกติจากผู้ใช้
5. ทดสอบรายงานหลังบ้านและไฟล์ CSV/Excel ด้วยข้อมูลจริงหลายช่วงวันที่
6. Privacy/Terms/ช่องปลอม ก่อนเปิดกลุ่มทดลอง

## ข้อมูลที่รอจากพี่บอล

1. ช่องทางติดต่อทางการที่ให้แสดงต่อสาธารณะ
2. เงื่อนไขรับประกันและคืนสินค้า
3. ข้อความหรือตราสำหรับลายน้ำภาพสินค้า
